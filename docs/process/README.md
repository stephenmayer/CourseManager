# How we work

The process kit lives in [`.claude/`](../../.claude/): skills in `.claude/skills/` (start at `build-process`), templates and reference in `.claude/process-kit/`. Working preferences: [`working-with-the-owner.md`](../../.claude/process-kit/reference/working-with-the-owner.md).

Project-specific lessons from the Timely CTO round (kept in Stephen's career repo, `opportunities/timely/take-home-handoff.md`): requirements first, the simplest thing that works, decisive choices with a reason and a trade-off, AI as accelerator not as the reasoning, generalize where natural, concrete user value, concise debrief.

Setting up, running, testing and the merge gate: [developer-guide.md](developer-guide.md).
